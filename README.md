# Student Dashboard

A modern and responsive Student Dashboard built using Next.js, Tailwind CSS, Framer Motion, and Supabase.

## Features

* Dark mode UI
* Bento Grid Dashboard Layout
* Responsive Design (Desktop, Tablet, Mobile)
* Animated Sidebar Navigation
* Dynamic Course Cards
* Animated Progress Bars
* Activity Graph Section
* Supabase Database Integration
* Loading Skeletons and Error Handling
* Framer Motion Animations

## Tech Stack

* Next.js (App Router)
* TypeScript
* Tailwind CSS
* Framer Motion
* Supabase
* Lucide React Icons

## Project Structure

* Server Components for data fetching
* Client Components for animations and interactions
* Reusable UI components
* Responsive Bento Grid layout

## Environment Variables

Create a `.env.local` file and add:

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url

NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

## Installation

```bash
npm install
npm run dev
```

## Deployment

The application is deployed on Vercel and connected to Supabase for database operations.
